# results/

Single canonical location for all processed outputs from toyproblem experiments.
Raw training data (metrics.csv, final.pt) lives in `runs/`.

## Directory layout

```
results/
  aggregated/
    summary.csv          — mean±std at convergence for every experiment × metric
                           Auto-generated. Rebuild after any new run:
                           python -m onpolicy.envs.toyproblem.analysis.aggregate_results

  post_hoc/
    sc_posthoc_mag/
      seed_0..4.json     — per-seed rate decomposition from post_hoc_coding.py
      aggregate.json     — mean±std across seeds (auto-generated by aggregate_results.py)

  figures/               — ALL figures for the toyproblem (single media directory)
    message_geometry.png — z-space / message-space / frac / confusion (Phase 1 vs Phase 2)
    message_geometry.pdf
    archive/             — pre-registry era figures (do not regenerate; historical record)
      sweep_stage_a/
        main/            — fig1_rate_distortion, fig2_channel_comparison
        appendix/        — appA–appH hyperparameter figures
        p2/              — p2_qphi_gap, p2_shannon_gap, p2_context_bounds (DLM era)
      p2_ablation/       — p2a_overview, p2a_dynamics, p2a_entropy_diagnostics, etc.
      p2_gradient_balance.{pdf,png}
      p2_per_dim_entropy.{pdf,png}

  reports/
    sweep_stage_a_baseline.md    — summary report from early sweep stage A
    channel_comparison_baseline.md

  README.md              — this file
```

## Regenerating outputs

```bash
# After any new training run
python -m onpolicy.envs.toyproblem.analysis.aggregate_results --verbose

# After running post_hoc_coding.py on a new checkpoint
cp runs/sc_ablation/<exp>/<seed>/post_hoc_decomposition.json \
   results/post_hoc/<exp>/seed_<seed>.json
python -m onpolicy.envs.toyproblem.analysis.aggregate_results

# message_geometry figure
KMP_DUPLICATE_LIB_OK=TRUE conda run -n marl_comms \
    python -m onpolicy.envs.toyproblem.analysis.message_geometry \
    --checkpoints <ckpt1> [<ckpt2> ...] --labels "..." \
    --out results/figures/message_geometry.png

# paper figures (F1–F20)
KMP_DUPLICATE_LIB_OK=TRUE conda run -n marl_comms \
    python -m onpolicy.envs.toyproblem.analysis.paper_figures \
    --runs_dir runs/sc_ablation --out_dir results/figures
```
